# New Game Plus Improvements

Hooks the game's real Challenge Mode / New Game Plus start.

Options:
- Optional starting bolt bonus (off by default)
- Skip the first in-level scene after NG+ begins

The original NG+ initialization always runs first.

Built for OpenRAC RAC1 PAL/NTSC-U. AI-assisted implementation. GPL-3.0-or-later.
